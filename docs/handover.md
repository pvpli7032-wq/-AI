## 已定规则（文档里没有或容易漏）

**资金：**
- 确认收货 → 延迟 N 天 → 系统余额 → 提现时真实打款。公司垫付，提现手续费 0。
- 冻结期全额退款算作废（`VOID`），已入账才算追回。`docs/progress.md` 里“线 11 待定”按此定。
- `recoveredAmount` 是累计联盟佣金追回额，线 11 算差额，按订单快照比例扣回，尾差落最后一项，不得用 `refund_fee`。
- 提成归属用线 9 记录的付款时邀请关系。无记录的历史单只补买家返利，上级提成转人工。
- 部分退款拿不到佣金金额时留空转人工；全额退款追回额 = 原佣金。

**提现：**
- 显示状态只有五个：审核中、打款中、已打款、打款失败、审核驳回，对应关系见 `design/admin.md`。
- 额度以下自动、以上人工，可设置。敞口上限和到限动作后台可控，默认转人工。敞口默认每小时算，提现时实时算。

**邀请和登录：**
- 无感登录。邀请码 4 位数往后排，只有新用户能绑邀请码，一级邀请。
- 订单没绑上时用户提交订单号，后台核对有交易且无主才绑定。已归别人的转人工，不覆盖。

**公共字典：** 变动类型、平台、订单状态、提现状态等只定义一处，经接口下发，页面不得写死。新类型带新资金规则时仍要写业务代码。

**暂定，按此实现：** `design/admin.md` 末尾两条，用户尚未确认。实现成容易调整，并在 PR 里标明。其他矛盾或没写的事，不要自己选，在 PR 里提问。

**不做：** 高佣（已取消并删除）、公众号、试算页、最差毛利校验、规则版本页面、差别定价、多级分销。
